Δωρεάν workshop: “From C++ to Qt: Achieving Software Excellence”

από Giorgos Apostolidis 22 Sep 2023

Είστε έτοιμοι να ξεκινήσετε ένα μεταμορφωτικό ταξίδι στον κόσμο του προγραμματισμού; Ελάτε μαζί με τον Tomaz Canabrava, έναν έμπειρο ανώτερο προγραμματιστή C++ στην CodeThink, σε μια καθηλωτική σειρά εργαστηρίων που θα σας εφοδιάσει με πολύτιμες δεξιότητες και γνώσεις για να διαπρέψετε στον προγραμματισμό C++ και την ανάπτυξη εφαρμογών Qt.

Φόρμα Συμμετοχής:https://forms.gle/zNMikdHhNLUHmZJv5 ΟΙ ΕΓΓΡΑΦΕΣ ΕΧΟΥΝ ΚΛΕΙΣΕΙ!

Μέρος 1: Εισαγωγή στη C++ (έναρξη 29 Οκτωβρίου, 6 εβδομάδες, online)

Στο πρώτο μέρος αυτού του εργαστηρίου, θα εντρυφήσετε στις βασικές αρχές του προγραμματισμού σε C++. Ο Tomaz θα σας καθοδηγήσει στις βασικές έννοιες, κάνοντάς το προσιτό ακόμα και αν είστε νέοι στον προγραμματισμό. Είτε είστε αρχάριος είτε θέλετε να ανανεώσετε τις δεξιότητές σας στη C++, αυτό το μέρος θα θέσει ισχυρά θεμέλια για το ταξίδι που ακολουθεί.

Μέρος 2: Ανάπτυξη εφαρμογών δια ζώσης (5 ημέρες, 2 ώρες/ημέρα)

Το δεύτερο μέρος του εργαστηρίου μας θα διεξαχθεί επί τόπου, όπου θα μάθετε την τέχνη της δημιουργίας εξαιρετικών διεπαφών χρήστη με το Qt. Ο Tomaz θα σας ξεναγήσει στις δυνατότητες του Qt, δίνοντάς σας τη δυνατότητα να δημιουργήσετε όμορφες, cross-platform εφαρμογές. Μην ανησυχείτε αν δεν είστε ειδικός- αυτό το εργαστήριο έχει σχεδιαστεί για να ανταποκρίνεται σε όλα τα επίπεδα δεξιοτήτων.

Τέλος: Open Source Hackathon (Μάρτιος, Σαββατοκύριακο)

Ως επιστέγασμα του μαθησιακού σας ταξιδιού, θα διοργανώσουμε έναν συναρπαστικό open source hackathon. Αυτή είναι η ευκαιρία σας να εφαρμόσετε τις νεοαποκτηθείσες γνώσεις σας σε C++ και Qt για να συνεισφέρετε σε πραγματικές εφαρμογές ανοιχτού κώδικα. Μείνετε συντονισμένοι για περισσότερες λεπτομέρειες- θα ανακοινώσουμε τη συγκεκριμένη ημερομηνία καθώς το μάθημα εξελίσσεται.

Πιστοποίηση

Για να κερδίσετε την πιστοποίησή σας, οι συμμετέχοντες πρέπει να συμμετάσχουν σε τουλάχιστον 5 από τα 6 μαθήματα σε κάθε μέρος. Αυτή η πιστοποίηση θα αποτελέσει απόδειξη της αφοσίωσής σας και των νεοαποκτηθέντων δεξιοτήτων σας στην ανάπτυξη της C++ και της Qt.

Διασφάλιση απορρήτου

Να είστε σίγουροι ότι τα προσωπικά σας δεδομένα θα παραμείνουν αυστηρά ιδιωτικά και εμπιστευτικά. Δεσμευόμαστε να διαφυλάξουμε τις πληροφορίες σας και δεν θα τις μοιραστούμε με κανέναν.

Περιορισμένη εγγραφή

Για να διασφαλίσουμε μια εξατομικευμένη μαθησιακή εμπειρία, περιορίζουμε την εγγραφή σε 40 συμμετέχοντες. Μην χάσετε αυτή την ευκαιρία να μάθετε από τον Tomaz Canabrava και να συνδεθείτε με ομοϊδεάτες σας που είναι παθιασμένοι με τη C++ και την Qt.

Εξασφαλίστε τη θέση σας τώρα και ξεκινήστε ένα ταξίδι από τη C++ στην Qt, όπου όχι μόνο θα κατακτήσετε την τέχνη της δημιουργίας εξαιρετικών διεπαφών χρήστη, αλλά και θα έχετε θετικό αντίκτυπο στον κόσμο του λογισμικού ανοιχτού κώδικα. Εγγραφείτε σήμερα και ξεκλειδώστε τις δυνατότητές σας! Αυτή η εκδήλωση διοργανώνεται από την ομάδα Open Source UOM, μια παθιασμένη ομάδα ενθουσιωδών φίλων του ανοιχτού κώδικα που έχει ως στόχο την προώθηση μιας ζωντανής κοινότητας προγραμματιστών.

Οι ώρες θα ανακοινωθούν σύντομα (σίγουρα όχι νωρίς το πρωί και αργά το απόγευμα) !
