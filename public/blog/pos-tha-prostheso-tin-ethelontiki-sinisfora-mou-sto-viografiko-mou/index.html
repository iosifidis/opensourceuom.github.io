Πως θα προσθέσω την εθελοντική συνεισφορά μου στο βιογραφικό;

από Efstathios Iosifidis 15 May 2023

Έχετε ξεκινήσει να μεταφράζετε ή να προωθείτε ένα έργο ανοικτού λογισμικού. Έχοντας την νοοτροπία της βεβαίωσης, αναρωτιέστε πως θα είστε σίγουροι ότι το έργο σας θα αναγνωριστεί από την κοινότητα. Πως μπορείτε να το εισάγετε στο βιογραφικό σας;

Οι παραπάνω ερωτήσεις σας είναι πολύ εύλογες. Η απάντηση σε όλες είναι είναι ασχοληθείτε με το SEO του username σας. Φροντίστε να αφήνετε το “στίγμα” σας στα έργα που συνεισφέρετε. Πως θα αφήσετε το στίγμα σας;

  1. Μεταφράσεις αρχείου po: Όταν μεταφράζετε κάποιο αρχείο, εφόσον έχετε εισάγει στις ρυθμίσεις του προγράμματος poedit το Όνομά σας και το email σας, αυτά καταγράφονται στο αρχείο και όταν το ανεβάζετε στον διακομιστή, αυτό έχει καταγραφεί. Σε μερικά αρχεία, υπάρχει κάποιο string που αναφέρεται στους μεταφραστές που εμφανίζονται στο μενού Περί.
  2. Μεταφράσεις tranifex-weblate-crowdin: Εδώ δεν χρειάζεται να κάνετε κάποια ρύθμιση. Η ρύθμιση ουσιαστικά είναι η εγγραφή σας.
  3. Λίστες ταχυδρομείου – ομάδες στα μέσα κοινωνικής δικτύωσης: Μπορεί να γράφετε κάποιο άρθρο ή να οργανώσετε κάποια εκδήλωση. Οπότε αυτό θα πρέπει να το επικοινωνήσετε με την κοινότητα. Αυτό γίνεται μέσα από τις λίστες ταχυδρομείου και στα μέσα κοινωνικής δικτύωσης.

Αφού αφήσετε το στίγμα σας, όταν πάτε σε κάποιο συνέδριο, θα συνδέσουν το username με πρόσωπο.

ΜΕΛΟΣ ΚΟΙΝΟΤΗΤΑΣ

Όπως έχουμε πει και σε άλλο άρθρο, σταματήστε να κυνηγάτε βεβαιώσεις συμμετοχής σε σεμινάρια και κυνηγήστε καλύτερα να γίνετε μέλος σε κάποια κοινότητα. Όταν πείτε ότι είστε μέλος της κοινότητας, αυτό σημαίνει ότι περάσατε από κρίση. Για να γίνει αυτό, είχατε κάνει κάποια αίτηση κάπου. Για να κάνετε αυτή την αίτηση, θα έχετε κάνει κάποια συνεισφορά. Στην επαγγελματική σας ζωή, για να γραφτείτε στο επαγγελματικό σας σύλλογο, θα χρειαστεί να προσκομήσετε την άδεια ασκήσεως επαγγέλματος (την αποκτάτε προσκομίζοντας το πτυχίο σας και πληρώνετε ένα χρηματικό ποσό) και γι να γίνετε μέλος, πληρώνετε ένα χρηματικό ποσό. Έχοντας την ιδιότητα μέλους του συλλόγου, σας δίνονται κάποια προνόμοια. Αυτό είναι πιο σημαντικό από το να πείτε ότι παρακολουθήσατε μια ημερίδα πάνω στον επαγγελματικό σας κλάδο. Ας δούμε σε ποιες κοινότητες μπορείτε να γίνετε επίσημο μέλος.

ΚΟΙΝΟΤΗΤΑ ΑΝΟΙΚΤΟΥ ΛΟΓΙΣΜΙΚΟΥ ΠΑΜΑΚ

Για να γίνεις μέλος στην κοινότητά μας, δεν χρειάζεται να έχετε συνεισφορά. Αρκεί η θέληση να συμμετάσχετε και να συνεισφέρετε εθελοντικά. Αυτό που θα αποκτήσετε είναι απαραίτητες γνώσεις που θα σας βοηθήσουν στην επαγγελματική σας ζωή. Καταρχήν εκφράστε την θέλησή σας στέλνοντας ένα mail στο linux-team@uom.edu.gr . Εμείς θα σας ζητήσουμε να συμπληρώσετε μια τυπική φόρμα για να σας γνωρίζουμε καλύτερα και να σας καθοδηγήσουμε σε ποιο/α projects μπορείτε να συμμετάσχετε. Σε κάποια από αυτά τα projects υπάρχουν και βεβαιώσεις που θα είναι υπογεγραμμένες από το Πανεπιστήμιο. Ο σκοπός της συνεισφοράς σας στα projects μας είναι να βελτιώσετε το SEO του username σας στο Github/Gitlab.

Εάν θέλετε να συμμετάσχετε στην κοινότητά μας, μπορείτε να μας στείλετε ένα mail στο linux-team@uom.edu.gr για να σας καθοδηγήσουμε στα επόμενα βήματα.

openSUSE member

Εφόσον έχετε κάνει μετρήσιμη συνεισφορά μπορείτε να γίνετε μέλος της κοινότητας openSUSE. Τι θεωρείται συνεισφορά; Μπορείτε να βοηθήσετε στην οργάνωση εκδηλώσεων, τεχνικές συνεισφορές, συγγραφή τεκμηρίωσης στο wiki, συγγραφή τεκμηρίωση γενικότερα, συμμετοχή στα openSUSE Forums και πολλές άλλες δραστηριότητες. Όλη η διαδικασία περιγράφεται στην ιστοσελίδα https://en.opensuse.org/openSUSE:Members. Η διαδικασία γίνεται μια φορά.

Τι προνόμια σας δίνει; Σας δίνει διεύθυνση @opensuse.org, μπορείτε να βάλετε το RSS της ιστοσελίδας σας στο planet openSUSE, μπορείτε να ψηφίσετε και να ψηφιστείτε στις εκλογές για το openSUSE Board. Τέλος θα είναι πιο εύκολο να αιτηθείτε υποστήριξη για να παρευρεθείτε σε κάποιο συνέδριο από το Travel Support Program.

Ubuntu member

Η διανομή Ubuntu είναι η διασημότερη διανομή στον κόσμο (άσχετα με το τι λέει το distroswatch). Και το Ubuntu έχει την ιδιότητα του member. Αυτά περιγράφονται στην κεντρική σελίδα στο wiki https://wiki.ubuntu.com/Membership. Υπάρχει ακόμα μια σελίδα στην κεντρική ιστοσελίδα του Ubuntu https://ubuntu.com/community/membership. Τέλος, επειδή έχει αλλάξει λίγο το σύστημα, υπάρχει ένα άρθρο στο blog (προσωπικά αυτό ακολούθησα). Δείτε το άρθρο https://ubuntu.com/blog/the-new-ubuntu-membership-process. Και στην συγκεκριμένη περίπτωση πρέπει να αποδείξετε ότι έχετε ικανοποιητική συνεισφορά στην κοινότητα για να σας αποδεχτούν ως μέλος. Καλό θα ήταν να έχετε και την στήριξη άλλων μελών Ubuntu. Η διαδικασία γίνεται μια φορά.

Τι προνόμια σας δίνει; Θα δούμε κάποια (περιγράφονται όλα στις παραπάνω σελίδες). Κλασικά ένα alias mail @ubuntu.com. Μπορείτε να βάλετε το RSS σας στο planet Ubuntu. Μπορείτε να ψηφίσετε όταν έχουν εκλογές. Θα σας στείλουν ένα πιστοποιητικό (βεβαίωση), υπογργραμμένο από τον Mark Shuttleworth, ως τιμητικό. Τέλος, το κυριότερο, είναι 50 άδειες για το Ubuntu Pro. Τι είναι αυτό; Με λίγα λόγια είναι το κανονικό Ubuntu LTS συν ενημερώσεις ασφάλειας για περισσότερα χρόνια και πακέτα από πριν. Μπορείτε να το χρησιμοποιήσετε ΜΟΝΟ για προσωπικά projects.

Fedora Ambassador

Στην κοινότητα Fedora, υπάρχει ο ρόλος του Ambassador που περιγράφεται στην ιστοσελίδα https://docs.fedoraproject.org/en-US/commops/latest/teams/ambassadors/. Ουσιαστικά είναι ο εκπρόσωπος της κοινότητας στην χώρα. Μιλάτε σε συνέδρια αλλά και διάφορες εκδηλώσεις, προσπαθείτε να καθοδηγήσετε τους χρήστες στην κοινότητα Fedora. Η όλη διαδικασία περιγράφεται στην σελίδα https://docs.fedoraproject.org/en-US/commops/latest/teams/become-an-ambassador/. Η διαδικασία γίνεται μια φορά. Για να γίνετε Ambassador θα πρέπει να βρείτε ένα/μια μέντορα για να σας καθοδηγήσει στα βήματά σας μέσα στην κοινότητα Fedora. Θα σας δώσει κάποιες πηγές και όταν τις μελετήσετε θα πρέπει να ξαναβρεθείτε για να σας κάνει ένα υποτυπώδες τεστ.

Ποια είναι τα προνόμιά σας; Αρχικά σας δίνει ένα alias mail @fedoraproject.org, μπορείτε να εισάγετε το RSS στο planet Fedora. Επίσης μπορείτε να ζητήσετε χρηματοδότηση για συμμετοχή σε συνέδρια ή ακόμα και για δικές σας εκδηλώσεις, αν χρειαστεί να καλυφθεί ένα ποσό για κάποιες αγορές. Υπάρχουν και άλλα παρόμοια με τα άλλα projects.

GNOME Foundation member

Το GNOME έχει δικό του Ίδρυμα (Foundation) που μπορείτε να δείτε στην ιστοσελίδα https://foundation.gnome.org/ (μάλλιστα έχει φωτογραφία από το GUADEC που διεξήχθη στο πανεπιστήμιό μας). Το GNOME έχει διαδικασία για να γίνετε μέλος του ιδύματος. Όλα τα μέλη βρίσκονται εδώ https://foundation.gnome.org/membership/ και ουσιαστικά από εδώ ξεκινάτε την αίτησή σας. Εδώ το σημαντικό είναι ότι πρέπει να έχετε 2 άτομα να στηρήξουν την αίτησή σας. Η διαδικασία γίνεται κάθε 2 χρόνια. Κάθε 2 χρόνια πρέπει να κάνετε ανανέωση.

Τα προνόμια που σας δίνει περιγράφονται στην σελίδα wiki https://wiki.gnome.org/MembershipCommittee/MembershipBenefits. Μερικά από αυτά είναι ένα alias mail @gnome.org, το RSS στο planet GNOME, να ψηφίσετε και να ψηφιστείτε, σας δίνει δωρεάν blog στο https://blogs.gnome.org/, μποείτε να στείλετε για υποστήριξη σε συμμετοχή σε συνέδρια στο travel support program και σας δίνει εκπτώσεις στο https://www.gandi.net/.

KDE ev member

Και το KDE έχει ίδρυμα ( https://ev.kde.org/) και μππορείτε να γίνετε μέλη. Όλα περιγράφονται στην σελίδα https://ev.kde.org/getinvolved/members/. Εδώ πρέπει να βρείτε ένα μέλος να σας προτείνει και να έχετε την υποστήριξη άλλων 2 μελών. Προφανώς για να γίνει κάτι τέτοιο πρέπει να έχετε κάνει συνεισφορά και να σας έχει δει κάποιο μέλος και να σας προτείνει.

Τέλος, και εδώ έχει προνόμια ως μέλος στο ίδρυμα KDE. Είναι ένα alias mail @kde.org, μπορείτε να ψηφίσετε αλλά και να ψηφιστείτε στο Board του KDE αλλά έχει και άλλα πολλά, παρόμοια με τα προηγούμενα.

Εάν έχετε οποιαδήποτε απορία, μπορείτε να μας στείλετε ένα mail στο linux-team@uom.edu.gr για να σας καθοδηγήσουμε στα επόμενα βήματα.
