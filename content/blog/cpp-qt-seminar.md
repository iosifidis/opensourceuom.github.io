## What is Qt and why should I care about it?

Qt is a highly performant, cross-platform, graphics library that is being used by companies such as Mercedes, Lufthansa and LG. For someone wanting to dive deeper into it, we have written a whole article about it [here](/qt-ena-isxiro-ergaleio-gia-tin-anaptiksi-efarmogon/). Also, it makes using C++ much easier in terms of developer experience and more productive, abstracting away all the technical details(important nonetheless, but time-consuming)

## Prerequisites

- Basic Object Oriented Programming principles(in youtube there is plenty of content around the topic, recommended: [https://www.youtube.com/watch?v=SiBw7os-\_zI](https://www.youtube.com/watch?v=SiBw7os-_zI))
- Having a working installation of [Qt Creator](https://www.qt.io/download)(you can get a licence, signing up with your student email)
- A basic understanding of CMake and a working installation(in the first and second course you can find more details and also [https://cliutils.gitlab.io/modern-cmake/chapters/basics.html](https://cliutils.gitlab.io/modern-cmake/chapters/basics.html))
- [VCPKG](https://learn.microsoft.com/en-us/vcpkg/get_started/overview) (package manager to add libraries, also explained in the part 1)

## Hackathon

Fix a bug in your favorite open-source Qt/C++ application and win prizes that amount up to 500EUR for the top 3 contestants. The hackathon will be held on the weekend with a duration of around 40hrs, with plenty of code to write, tasty snacks, and of course a lot of caffeine.

## Course Outline

**Duration**: 4 days for the Qt Course + 2 days for a hackathon

**Total**: 6 days

**Hours per Day**: 3.5 hours divided in 2 hours lessons, 1 hour student questions(more practical session, writing code, debugging, fixing mistakes)

**Monday:**

– Basic Qt6 Project

– CMake

– C++ Recap

– The Qt Event Loop

– Signals / Slots

– Hangman CLI Game with Qt Signals / Slots and Eventloop

**Tuesday**:

– QML Intro

– Animations

– Timers

– Pong Game

**Wednesday:**

– Classic Widgets

– QPainter / Semaphore / Clock Example

– QQuickPaintedItem

– Mixing QML with Classic Widgets

**Thursday**:

– Networking (QNetworkAccessManager / QNetworkReply)

– Image Handling (Change Colors / Access Pixels / Paint)

– File Handling (QFile / QIODevice)

– Threads (Resizing a bunch of files in disk)

**Friday:**

– Creating a fully featured music player:

– VCPKG

– Integrating External Libraries

– Using KConfigXT for user configuration

– Playing Multimedia using Qt (mp3 / videos)
