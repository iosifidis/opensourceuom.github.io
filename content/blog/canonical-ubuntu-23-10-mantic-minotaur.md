Η ενισχυμένη ασφάλεια, η βελτιωμένη ανακάλυψη εφαρμογών για υπολογιστές και η υποστήριξη νέου υλικού οδηγούν αυτήν την τελευταία έκδοση του Ubuntu.

![Ubuntu 23.10 Mantic Minotaur wallpaper](/storage/2023/09/wallpaper_minotaur_colour_1920x1080-1024x576.png)

Σήμερα η Canonical ανακοίνωσε την κυκλοφορία του Ubuntu 23.10, με την κωδική ονομασία “Mantic Minotaur”, διαθέσιμο για λήψη και εγκατάσταση από τη διεύθυνση [https://ubuntu.com/download](https://ubuntu.com/download/?rel=opensource.uom.gr).

«Σε αυτήν την έκδοση έχουμε ανεβάσει τον πήχη για το τι σημαίνει ασφάλεια από προεπιλογή για το Ubuntu και βάλαμε τις βάσεις για την επόμενη μακροπρόθεσμη υποστηριζόμενη έκδοση μας». είπε ο Oliver Smith, Senior Product Manager για το Ubuntu στην Canonical. «Είμαστε ενθουσιασμένοι που οι χρήστες θα δοκιμάσουν την πρεμιέρα της αποθήκευσης κλειδιού κρυπτογράφησης δίσκου με υποστήριξη υλικού στο Ubuntu Desktop, παράλληλα με το νέο App Center που διευκολύνει την εύρεση του λογισμικού που χρειάζεστε».

## Βελτιωμένη ασφάλεια

Οι παραδοσιακές μέθοδοι κρυπτογράφησης πλήρους δίσκου απαιτούν μια φράση πρόσβασης για την ολοκλήρωση της διαδικασίας εκκίνησης, αναγκάζοντας τους διαχειριστές να επιλέξουν μεταξύ της ασφάλειας της συσκευής και της δυνατότητας διαχείρισης.

Το Ubuntu Desktop 23.10 διαθέτει υποστήριξη για κρυπτογράφηση πλήρους δίσκου με υποστήριξη υλικού, όπου τα κλειδιά κρυπτογράφησης αποθηκεύονται στο Trusted Platform Module (TPM) και ανακτώνται αυτόματα από πιστοποιημένο λογισμικό εκκίνησης. Ευρύτερη υποστήριξη υλικού για αυτήν τη δυνατότητα θα φτάσει το επόμενο έτος μαζί με πρόσθετες επιλογές διαμόρφωσης και διαχείρισης κρυπτογράφησης στο Ubuntu 24.04 LTS.

Η κρυπτογράφηση πλήρους δίσκου που υποστηρίζεται από το TPM είναι οι τίτλοι μιας ευρύτερης επένδυσης στην προεπιλεγμένη στάση ασφαλείας του Ubuntu, η οποία περιλαμβάνει επίσης μια αλλαγή στον πυρήνα του Ubuntu για την αντιμετώπιση μιας κοινής διαδρομής εκμετάλλευσης.

Οι μη προνομιούχοι χώροι ονομάτων χρηστών χρησιμοποιούνται από πολλές κοινές εφαρμογές, όπως τα προγράμματα περιήγησης στο Διαδίκτυο, για τη δημιουργία ασφαλών sandbox. Ωστόσο, εκθέτουν τις διεπαφές του πυρήνα που συνήθως περιορίζονται σε διεργασίες με δικαιώματα root που μπορούν να δημιουργήσουν σημαντικές ευπάθειες ασφαλείας. Για την αντιμετώπιση αυτού του προβλήματος, ο πυρήνας του Ubuntu υποστηρίζει τώρα μια πρόσθετη λειτουργία που απαιτεί από τα προγράμματα να έχουν προφίλ AppArmor προκειμένου να χρησιμοποιούν μη προνομιούχους χώρους ονομάτων χρήστη, μειώνοντας σημαντικά την επιφάνεια επίθεσης τους. Οι εφαρμογές στα αρχεία του Ubuntu διαθέτουν πλέον τέτοια προφίλ AppArmor για να διασφαλίζουν τη συμμόρφωση με αυτήν την πολιτική όταν είναι ενεργοποιημένη.

## Αναβαθμισμένη ανακάλυψη εφαρμογής

![](/storage/2023/10/app-discovery.webp)

Ο κόσμος των εφαρμογών ανοιχτού κώδικα επεκτείνεται συνεχώς. Όσο μεγαλύτερο γίνεται αυτό το πλούσιο οικοσύστημα, τόσο πιο δύσκολο είναι να ανακαλύψετε, να διαχειριστείτε και κυρίως να εμπιστευτείτε το λογισμικό που είναι εγκατεστημένο στο μηχάνημά σας.

Το νέο Κέντρο Εφαρμογών του Ubuntu Desktop είναι ένας γρήγορος, διαισθητικός και φιλικός προς τον χρήστη κόμβος που υποστηρίζει μορφές πακέτων snap και deb. Το App Center αξιοποιεί τα πλούσια μεταδεδομένα που παρέχονται από το Canonical Snap Store. Όλες οι εφαρμογές που δημοσιεύονται στο Snap Store περνούν από αυστηρούς ελέγχους ασφαλείας για να διασφαλιστεί ότι μόνο τα απαραίτητα δικαιώματα είναι ενεργοποιημένα από προεπιλογή. Μια ισχυρή διαδικασία επαλήθευσης υπογραφής διασφαλίζει επίσης ότι τα Snaps δεν μπορούν να τροποποιηθούν από κανέναν εκτός από τον εκδότη.

## Υποστήριξη για Raspberry Pi 5 και SiFive HiFive Pro P550

Το Ubuntu 23.10 προσφέρει εκτεταμένες επιλογές για προγραμματιστές που θέλουν να στοχεύσουν τις πιο πρόσφατες πλατφόρμες και αρχιτεκτονικές αιχμής.

Το Ubuntu συνεχίζει να επιβεβαιώνει τη δέσμευσή του στο Raspberry Pi ως πλατφόρμα πρώτης κατηγορίας για περιπτώσεις χρήσης Desktop, Server και IoT. Το Ubuntu 23.10 Desktop and Server θα υποστηρίζει το ολοκαίνουργιο Raspberry Pi 5 από την ημέρα κυκλοφορίας, χάρη στη στενή μας συνεργασία με το Raspberry Pi Foundation.

«Με το Raspberry Pi 5 έχουμε ενισχύσει τη δύναμη και την απόδοση του πιο δημοφιλούς υπολογιστή στον κόσμο για να προσφέρουμε μια ολοκληρωμένη πλατφόρμα προγραμματιστών». δήλωσε ο Gordon Hollingworth, Chief Technology Officer – Software στο Raspberry Pi Trading, «Είμαστε ενθουσιασμένοι που βλέπουμε πώς η κοινότητα του Ubuntu αξιοποιεί αυτή τη δύναμη για να δημιουργήσει καινοτόμες και συναρπαστικές νέες εμπειρίες».

Με βάση την επιτυχημένη συνεργασία που έφερε το Ubuntu στις πλατφόρμες ανάπτυξης SiFive HiFive RISC-V, συμπεριλαμβανομένου του HiFive Unmatched, η Canonical συνεχίζει να είναι κορυφαίος υποστηρικτής του οικοσυστήματος RISC-V. Το Ubuntu 23.10 θα είναι διαθέσιμο στο SiFive HiFive Pro P550 κατά την κυκλοφορία του.

Η ενισχυμένη ασφάλεια, η βελτιωμένη ανακάλυψη εφαρμογών για επιτραπέζιους υπολογιστές και η υποστήριξη νέου υλικού οδηγούν την τελευταία έκδοση του Ubuntu 23.10 Mantic Minotaur. Με βάση την επιτυχημένη συνεργασία που έφερε το Ubuntu στις πλατφόρμες ανάπτυξης SiFive HiFive RISC-V, συμπεριλαμβανομένου του HiFive Unmatched, η Canonical συνεχίζει να είναι κορυφαίος υποστηρικτής του οικοσυστήματος RISC-V. Το Ubuntu 23.10 θα είναι διαθέσιμο στο SiFive HiFive Pro P550 κατά την κυκλοφορία του.

«Μαζί, η SiFive και η Canonical συνεχίζουν να προσφέρουν κορυφαίες λύσεις υλικού/λογισμικού που αποτελούν βασικούς παράγοντες για τους προγραμματιστές RISC-V, βοηθώντας στη μετακίνηση του οικοσυστήματος RISC-V σε εφαρμογές που απαιτούν υπολογισμό υψηλότερης απόδοσης», δήλωσε ο Phil Dworsky, Global Head of Strategic Alliance στο SiFive, «Ο συνδυασμός Canonical Ubuntu και της οικογένειας SiFive Performance™ των IP επεξεργαστών ενισχύει τους προγραμματιστές με τις πλατφόρμες που είναι απαραίτητες για τη διαμόρφωση του μέλλοντος των υπολογιστών, στο RISC-V».

## Βαθύτερη ενοποίηση για οικεία εργαλεία διαχείρισης

Προηγουμένως, η διαμόρφωση δικτύου στο Ubuntu απαιτούσε από τους διαχειριστές να προσαρμόσουν τις ροές εργασίας τους ανάλογα με το αν στόχευαν περιπτώσεις χρήσης επιτραπέζιων υπολογιστών ή διακομιστή. Για να προσφέρει μια απρόσκοπτη εμπειρία δικτύωσης, το Ubuntu Desktop χρησιμοποιεί τώρα το Netplan, το δηλωτικό εργαλείο διαμόρφωσης δικτύωσης Linux που χρησιμοποιείται στον διακομιστή Ubuntu.

Για διαχειριστές που διαχειρίζονται συνδυασμένους «στόλους» επιτραπέζιων υπολογιστών Windows και Ubuntu, το ADsys, το πρόγραμμα-πελάτης πολιτικής ομάδας Active Directory που διατίθεται με το Ubuntu Pro, υποστηρίζει τώρα την αυτόματη εγγραφή πιστοποιητικού μηχανήματος από τις υπηρεσίες πιστοποιητικών Active Directory.

Για να συμπληρώσει το εύρος βελτιώσεων στη διαχείριση στόλου Ubuntu, ο πελάτης Ubuntu Pro παρέχει τώρα έναν απλοποιημένο οδηγό εγγραφής Landscape με πρόσθετη καθοδήγηση για μαζικές εγγραφές Landscape για βελτιστοποίηση της ανάπτυξης σε κλίμακα.

## Δημοφιλή πρόσθετα για ένα ανανεωμένο Docker

Οι προγραμματιστές του Docker θα χαρούν να διαπιστώσουν ότι το Ubuntu 23.10 περιλαμβάνει την πιο πρόσφατη έκδοση του Docker 24.0.5 μαζί με δύο από τα πιο δημοφιλή πρόσθετα Docker, το docker-buildx και το docker-compose-v2. Με αυτόν τον τρόπο, το Mantic μειώνει την εξάπλωση των αποθετηρίων για τους μηχανικούς και καθιστά τα περιβάλλοντα ανάπτυξης λιγότερο επαχθή στη διατήρηση.
